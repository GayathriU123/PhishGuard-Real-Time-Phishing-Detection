# Demo script

Use only safe, preloaded test fixtures; do not open suspicious URLs.

1. Explain the scope: supervised URL detection with separate email heuristics.
2. Submit a benign example URL and inspect static feature evidence.
3. Paste an example email and inspect parsed sender, extracted links, and clearly labelled message rules.
4. Open the investigation and review queue; submit a reviewer decision with a reason.
5. Show the audit timeline and original recommendation beside the reviewer outcome.
6. Open Model Lab and report only measured held-out metrics from an actual trained artifact. If none exists, show the explicit untrained state.

Do not claim real inbox quarantine or protection guarantees.
